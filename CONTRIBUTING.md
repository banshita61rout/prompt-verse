# Contributing to Prompt Verse

Thanks for considering a contribution. This project welcomes bug fixes, feature ideas, and general improvements.

## Getting started

1. Fork the repo and clone your fork
2. Follow the setup steps in the README for both `backend` and `frontend`
3. Create a branch off `main` for your change:
   ```bash
   git checkout -b fix/short-description
   ```

## Making changes

- Keep backend and frontend changes in separate commits where it makes sense
- Match the existing code style rather than introducing a new one (this project intentionally keeps things simple and readable over clever)
- Test your change locally by running both the backend and frontend dev servers before opening a PR
- If you're adding a new environment variable, update the relevant `.env` file and the README's environment variable table

## Submitting a change

1. Push your branch to your fork
2. Open a pull request against `main` with a clear description of what changed and why
3. Link any related issue if one exists

## Reporting a bug

Open an issue with:

- What you expected to happen
- What actually happened
- Steps to reproduce it
- Any relevant console/terminal error output

## Suggesting a feature

Open an issue describing the feature and the problem it solves. Not every suggestion will get built, but all of them are read.

## Code of conduct

Be respectful. Disagreements about implementation are fine, personal attacks are not.
